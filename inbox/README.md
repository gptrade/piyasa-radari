# Rapor kutusu

Aracı kurum raporlarını, değerleme raporlarını veya kendi notlarını bu klasöre yükle
(GitHub'da **Add file → Upload files**). Bir sonraki çalıştırmada Claude raporu okur,
hedef fiyat / tavsiye / tahmin değişikliklerini çıkarır ve panele bir "Rapor" kartı olarak ekler.

- Desteklenen türler: `.pdf`, `.txt`, `.md`
- Dosya adında hisse kodu ve tarih olursa en iyi sonuç alınır: `2026-09-27_VAKBN_kurum-adi.pdf`
- Rapor metninin kendisi panele yazılmaz; yalnızca Claude'un özeti yayınlanır.

**Önemli:** Repo herkese açıksa buraya yüklediğin dosyalar da herkese açıktır.
Ücretli/abonelik raporlarını yükleyeceksen repoyu private yap (GitHub Pages'in private
repodan yayın yapması GitHub Pro ister) ya da bu klasörü kullanma.
